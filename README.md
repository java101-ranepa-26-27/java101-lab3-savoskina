## Что делаем

В коде появляется сущность **«Университет»**. Университет содержит список студентов и методы
работы со студентами:

- **зачислить** — создать студента по имени, без оценок, и записать на 1 курс;
- **перевести на следующий курс** — если средний балл студента больше `2.5`, операция доступна;
  если средний балл не больше `2.5` — вывести сообщение и перевести студента в статус
  «отчислен»; если студент на последнем курсе и перевод разрешён — перевести его в статус
  «выпустился»;
- **отчислить** — выставить студенту статус «отчислен»;
- **поставить оценку** — выставить конкретному студенту оценку;
- **напечатать сводку** — напечатать всех студентов, их состояние и оценки.

Студент получает дополнительные поля: **курс** и **enum-состояние** со значениями «учится»,
«отчислен», «выпустился». Номер студенческого билета — `long`.

**Студент закрыт для создания снаружи.** Все конструкторы — `private`.
Студент создаётся **статическим методом**, который вызывает университет;
в `Main` студента напрямую не создавай. Университет и студент лежат в одном пакете, поэтому
статический метод создания доступен коду пакета, но не снаружи. В итоговом сценарии создавать
студента должен только университет.

Курсов четыре: с `1` по `4`. Оценка — целое число от `2` до `5`. Средний балл — дробное число;
если оценок нет, он равен `0`.

Университет сам выдаёт каждому зачисленному уникальный номер студенческого билета (`long`) —
по порядку: `1`, `2`, `3`, … Операции с конкретным студентом идут по этому номеру.

**Отказ оформляется исключением `IllegalArgumentException` с сообщением.** Все отказы —
неверный аргумент, запрещённая операция, неизвестный номер билета — бросают
`IllegalArgumentException` с понятным сообщением. Вот реальный отказ на примере перевода
отчисленного:

```java
public void transferToNextCourse(long studentId) {
    Student student = findStudent(studentId);
    if (student.getState() != StudentState.ENROLLED) {
        throw new IllegalArgumentException("студент уже отчислен");
    }
}
```

Имена методов и enum-констант здесь — пример; важна форма отказа:
`throw new IllegalArgumentException(...)`.

Отчисленный и выпустившийся студенты не участвуют в операциях: перевод, оценка и повторное
отчисление для них — исключение. Зачисление всегда создаёт нового студента.

### Сценарий в `Main.main`

Создай экземпляр университета и проверь все варианты поведения — шесть шагов:

1. создай университет, зачисли 2–3 студентов и поставь им оценки;
2. переведи студента со средним баллом больше `2.5`;
3. переведи студента со средним баллом `2.5` или меньше — должно появиться сообщение, а студент
   стать отчисленным;
4. переведи студента с четвёртого курса — он должен стать выпустившимся;
5. отчисли студента и попробуй операцию с отчисленным — должен появиться отказ;
6. напечатай сводку.

В итоговом сценарии студента в `Main` напрямую не создавай — только через университет.
Ввод с клавиатуры в сценарии не используется.

## Как запустить тесты

В шаблоне лежат тесты, которые проверяют поведение общей части.
Они не требуют конкретных имён методов и полей: тесты сами находят класс университета,
операции и поля студента по тому, что они делают. Но несколько вещей должны совпадать,
иначе тесты не смогут ничего найти:

- точка входа — класс `Main` с методом `main`;
- студент — класс `Student` в пакете `ru.ranepa`;
- университет — отдельный класс в пакете `ru.ranepa` с конструктором без аргументов;
- зачисление — метод университета с одним параметром `String`;
- операции с конкретным студентом — методы университета с параметром `long` (номер билета);
- у студента есть поле `long` — номер билета, поле `int` — курс и enum-поле состояния;
- сводка — метод университета без параметров, который печатает или возвращает `String`.

Имена этих методов и полей, название класса университета и enum-констант могут быть любыми.
Формат сводки тоже свободный: важно, чтобы в ней читались имена, оценки и состояния.

### Что проверяют тесты

Общая часть (17 тестов):

- студент закрыт на создание: все конструкторы `private`;
- номера билетов `long` идут по возрастанию;
- средний ровно `2.5` — отчисление, без оценок — тоже;
- перевод с 3 курса ведёт на 4, с 4 курса — выпускает;
- с 4 курса с низким средним — отчисление, а не выпуск;
- отказы: повторное отчисление, операции с отчисленным и выпускником, неизвестный билет,
  оценки `1` и `6`;
- сводка показывает имена, оценки и все три состояния.

`Main` (1 тест): сценарий доходит до конца и печатает три состояния.
